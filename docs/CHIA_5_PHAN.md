# Chia năm phần nhập mã nguồn

Đây là phân chia file để nhập bản code đã có, không phải xác nhận tác giả ban đầu. Các phần không chạy độc lập.

| Phần | Công việc | Người nhận |
|---|---|---|
| 1 | Giao diện React | Nhóm điền tên |
| 2 | model/ và policy/ | Nhóm điền tên |
| 3 | BookingService, BookingValidator, DefaultBookingValidator, IdGenerator | Bùi Minh Đăng — đề xuất trước đó |
| 4 | handler/, dto/, exception/, CorsConfig, StudentService, RoomService | Nhóm điền tên |
| 5 | Repository, JSON, test, cấu hình, script và tài liệu nguồn | Nhóm điền tên |

Xem DANH_SACH_FILE.md để biết từng đường dẫn chính xác. Một file chỉ thuộc một phần. Phần 5 nhiều file hơn vì gồm cả tài liệu, cấu hình và tài nguyên đã build.
